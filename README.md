# 김정은 사진 퍼즐 게임

브라우저에서 바로 실행되는 슬라이딩 퍼즐로, 사용자가 준비한 김정은 사진을 조각 내어 맞출 수 있습니다.

## 실행 방법

1. `index.html` 파일을 더블 클릭하거나 `Live Server` 같은 정적 서버로 열어 주세요.
2. `assets` 폴더에 사용할 사진을 넣고, 화면 위쪽의 **사진 불러오기** 버튼으로 파일을 선택합니다.
3. `섞기` 버튼을 눌러 게임을 시작하고, 조각을 이동해 원본 이미지를 완성해 보세요.

## 기능

- 3×3, 4×4, 5×5 슬라이딩 퍼즐 지원
- 이동 횟수 및 시간 기록
- 키보드 화살표로도 조작 가능
- 로컬 파일 업로드로 즉시 커스터마이징

사진은 사용자가 직접 제공해야 하며, 저작권 및 초상권을 준수해 주세요. 기본 경로는 `./assets/kim-photo.jpg` 이므로 동일한 이름의 파일을 넣으면 자동으로 불러옵니다.
