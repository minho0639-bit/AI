# 온라인으로 마음을 담아 편지를 직접 전달하는 서비스 팬레터포스트

## 콘셉트
- **슬로건**: 온라인에서 쓰고, 오프라인으로 닿는 마음
- **무드**: 밝은 파스텔 + 글로시 카드 UI, 2025년 트렌드인 모던 서브컬처 감성

## 랜딩 섹션 구성
1. 히어로: 감성적인 카피 + CTA 두 개(편지 쓰기 / 서비스 소개)
2. 핵심 기능: 온라인 작성 → 고급 인쇄 → 우편 발송 3단계 플로우
3. 감성 기능 강조: 고급지∙캘리그라피∙맞춤 스티커 등
4. 후기 / SNS 반응: 신뢰도 확보
5. FAQ 및 최종 CTA: 행동 유도

## 구현 메모
- 순수 HTML/CSS (+ 약간의 JS)로 반응형 구성
- Glassmorphism 카드, 컬러 그라디언트, 마이크로 인터랙션 사용
- 모바일에서는 세로 스택, 데스크톱에서는 그리드/플렉스 활용
